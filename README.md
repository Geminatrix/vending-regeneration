# VEND // REGENERATE

A rainy nighttime alley. A small expressive kid. A humming vending machine that acts like a character.

Type a word, phrase, or emoji. The machine invents a strange item, dispenses it, and remakes the player, the weather, the machine — or all three.

## Play

- **Sites (Higgsfield):** https://vend-regenerate.higgsfield.app
- **Local:** `npm start` then open http://127.0.0.1:4173

Discoveries and transforms are saved in the Codex (localStorage on the standalone build; room persistence on Sites).

## Loop

1. Type something weird (`rain`, `🔥`, `too honest`…)
2. Watch the can drop and the alley change
3. Browse Items / Transforms in the Codex
4. Vend again

Pixel-art-inspired procedural animation. Cute, uncanny, funny, occasionally ominous.
